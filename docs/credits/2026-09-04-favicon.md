# Favicon

- Asset: `public/favicon.ico`
- Provenance: original black-and-white anime side-profile artwork generated with Codex Image Generation on 2026-09-04 from the user's approved visual direction.
- Usage: served unchanged as a static file at `/favicon.ico`, explicitly referenced by layout metadata. The ICO contains an RGB PNG that browsers accept but the Turbopack metadata-image decoder rejects; serving the original bytes directly avoids decoding it during builds.
- Licensing: generated project asset; no third-party source artwork was used.
