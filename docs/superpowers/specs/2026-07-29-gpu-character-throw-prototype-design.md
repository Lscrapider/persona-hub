# GPU 骨骼角色甩卡技术样机设计

- 日期：2026-07-29
- 状态：用户已确认实施
- 目标视口：1920×1080、2560×1440
- 视觉依据：`docs/design/assets/homepage-direction-02.png`

## 目标

保持现有首页构图、文案、导航、项目内容和卡片到页面的 DOM 转场，
把平面人物舞台升级为真正由 GPU Skinning 渲染的骨骼角色。鼠标只在
作者设定范围内轻微环绕镜头；触发主操作后，角色完成甩臂，卡片先跟随
右手骨骼，再在确定释放帧脱手并接入现有飞向镜头的项目转场。

## 样机边界

首轮使用 three.js 官方 `RobotExpressive` CC0 模型验证完整技术链路。
它是可替换的低多边形代理，不是最终角色设计，也不改变既定原创怪盗角色
方向。最终角色仍需独立建模、绑定和制作专用 `throw` 动画。

样机必须：

- 使用真实 GLB、骨骼、AnimationMixer 和 GPU Skinning。
- 使用 `Idle` 作为待机动画，使用 `Punch` 作为临时甩卡动作。
- 卡片释放前从右手掌骨读取世界姿态；释放后保持同一世界姿态进入飞行。
- 不使用自由 OrbitControls，不允许用户破坏首页构图。
- 保留静态角色海报作为加载失败和 `prefers-reduced-motion` 降级。
- 不增加实时阴影、全屏后处理或倒壳描边。

## 场景结构

```text
ExperienceCanvas
└── ExperienceScene
    ├── CameraRig
    ├── Generated background plane
    ├── GpuCharacter
    │   ├── cloned GLB skeleton
    │   ├── Idle / Punch actions
    │   └── Palm2R hand anchor
    └── ProjectCard
        ├── attached pose from hand anchor
        └── released quadratic flight
```

`GpuCharacter` 每帧先更新骨骼；`ProjectCard` 随后读取手部世界矩阵。
卡片始终由 R3F 挂在场景根下，只复制世界姿态，不在释放帧重新挂载。

## 动画时间

| 时间 | 角色 | 卡片 | 镜头 / DOM |
| --- | --- | --- | --- |
| 0–270ms | Punch 蓄力与挥臂 | 跟随右手 | 指针影响回正 |
| 270ms | 到达释放姿态 | 缓存世界姿态 | 镜头开始推进 |
| 270–780ms | 动作完成 | 飞向镜头 | DOM 卡片开始接管 |
| 500–1000ms | 角色退为背景 | 卡片覆盖视口 | 扫描线揭示项目预览 |
| 1020ms | — | — | 更新真实项目路由 |

角色动作使用线性归一化时间；卡片飞行可使用 `power3.inOut`。

## 视觉处理

- 背景：从现有舞台图编辑出的无人黑红背景。
- 模型材质：黑色主体、浅色结构件、绯红面部/状态细节。
- 灯光：一个暖色方向光、一个红色点光和环境光；全部无阴影。
- 镜头：待机 yaw 约 ±3°、pitch 约 ±2°；投卡时回正并轻推。
- 卡片：沿用现有真实 Three.js 厚卡、项目纹理和红色轨迹。

## 性能预算

- 样机模型：453 KiB、3,237 三角面、43 个关节、3 个材质。
- DPR：按约 500 万物理像素预算计算，最高不超过 1.5。
- 无实时阴影、无后处理、无倒壳描边。
- 桌面目标：待机和投卡均保持流畅；2K 不出现页面溢出。
- 最终角色预算仍遵循原规格：35k–50k 三角面、最多 70 根骨骼、
  最多 3 个材质、压缩 GLB 不超过 4.5MB。

## 验收

- 角色是可转镜头观察的真实 3D 模型，不是平面纹理。
- 待机动画可见，点击后角色先动、卡片后脱手。
- 释放帧无明显跳位，卡片继续完成现有项目页转场。
- 1920×1080 和 2560×1440 构图完整且无溢出。
- `prefers-reduced-motion` 不挂载 WebGL 角色。
- TypeScript、ESLint、生产构建和浏览器控制台检查通过。
